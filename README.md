# SmartBudgetManagger
A project for managing Budget.
This software record both the monthly income and expenses of many categories (food, rent, transport….) of a user and calculates the balance using functions. And since there is a limit of a budget, this software tells exactly when a user exceed the limit and gives them a warning. Plus it gives a visualization of the categories of expenses in a chart so the user could understand correctly where is destinations of their expenses.

In order to use this workbook, we need Excel, so the user should have even a basic bit of knowledge about how to use it correctly. We also need the data or the informations about the income and the expenses.

In order to start the process, the user enters there expenses and there income in the transactions worksheet, the software automatically calculates their balance and give them a chart of their expenses plus the budget limit and if they reached it or not. In the Dashboard worksheet.
